# Third-Party Notices

Map data is credited separately in [DATA-CREDITS.md](DATA-CREDITS.md). Character models, vehicles, buildings, and utility furniture are original procedural Three.js geometry. The sections below cover third-party assets and runtime packages shipped in the browser bundle.

## Environment Assets (CC0-1.0)

Textures by **ambientCG**, released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) ([ambientCG license](https://docs.ambientcg.com/license/)):

| Source | Use |
| --- | --- |
| [Asphalt010](https://ambientcg.com/view?id=Asphalt010) | Vehicle road surface |
| [Concrete034](https://ambientcg.com/view?id=Concrete034) | Concrete/plaster walls, flat roofs, paths, and edges |
| [Bricks051](https://ambientcg.com/view?id=Bricks051) | Selected residential/construction facades |
| [Grass004](https://ambientcg.com/view?id=Grass004) | Ground and mapped green surfaces |
| [CorrugatedSteel005](https://ambientcg.com/view?id=CorrugatedSteel005) | Shed and garage roofs |

**[Painted Wooden Bench](https://polyhaven.com/a/painted_wooden_bench)** by **Poly Haven**, released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) ([Poly Haven license](https://polyhaven.com/license)). The source glTF (630 triangles) is scaled to 1.25 m wide and instanced across campus.

`public/visual/manifest.json` records download URLs, SHA-256 checksums, and byte counts for sources and bundled desktop (1K) and mobile (512 px) WebP derivatives generated by `scripts/prepare-visual-assets.py`. No external asset-host requests occur at runtime.

## Project Media

- **Voice reactions (`public/audio/npc/`)**: Owner-supplied MP3 recordings (see `public/audio/README.txt`). No text-to-speech or external audio API is used.
- **Landing & character artwork (`src/assets/`)**: Project artwork (`campus-story-bg.webp`, `portrait-hujur.png`, `portrait-niqab.png`) provided by the repository owner for the game landing screen.
- **Campus reference sources (`references/campus/SOURCES.md`)**: Metadata and attribution manifest for Wikimedia Commons reference photos consulted offline during landmark research (the reference JPEGs are not bundled in this repository).
